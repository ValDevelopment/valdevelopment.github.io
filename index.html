Clinical Trial Safety Analysis

Built a full CDISC SDTM/ADaM analysis pipeline in R using a public 254-patient Alzheimer's clinical trial dataset, covering baseline demographics, adverse event summarization, and time-to-event survival analysis.

Modeled time to adverse event using Kaplan-Meier curves and a Cox proportional hazards model, identifying a dose-response safety signal with hazard ratios of 4.15 and 5.03 versus placebo. Confirmed the finding through an age-adjusted sensitivity analysis.

League of Legends Win Prediction & Analytics

Analyzed more than 47,000 professional League of Legends games to model win prediction using XGBoost, achieving an AUC of 0.84. Also forecasted meta-trend shifts with ARIMA and ETS models and built a bootstrapped Elo rating system for cross-region team strength.

Built an interactive Tableau dashboard visualizing the model's early-game predictors and comparing raw win-rate splits with multivariate findings across game years.

FAERS Disproportionality Analysis: Semaglutide

Conducted a post-market drug safety signal detection analysis using FDA FAERS Q4 2025 data for semaglutide products, including Ozempic, Wegovy, and Rybelsus. Applied PRR, ROR, and chi-square disproportionality methods with Haldane-Anscombe correction across 3,279 primary-suspect reports.

Built the analysis pipeline independently in Python and SAS, validated both implementations to produce identical results, and reviewed flagged signals against MedDRA coding noise and published GLP-1 safety literature.

Clinical Trial Power Calculator

Built a two-arm clinical trial sample size and power calculator in Python and Streamlit. The application supports continuous, binary, and time-to-event endpoints using closed-form methods alongside simulation-based power estimates.

Implemented noncentral t, arcsine, and Schoenfeld formulas, as well as simulations that fit ANCOVA, logistic regression, and Cox proportional hazards models to synthetic trial data. Validated the formulas against independent benchmarks and demonstrated differences between closed-form power targets and regression-based Wald tests.
